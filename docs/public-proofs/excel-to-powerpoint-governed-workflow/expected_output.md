# Expected presentation output

The bounded proof maps the synthetic input and `deck_spec.json` to three presentation views:

1. **Title slide** — supplier-performance subject and synthetic-public-proof label.
2. **Executive summary** — counts for categories that are on track, categories requiring review, and total source rows.
3. **Category detail** — a table containing the selected source fields and status values.
